Development Process:

I started by looking at the screenshot to understand how the page was supposed to look. I paid attention to the colors, layout, and where everything was placed. After that, I wrote the CSS and linked it to the HTML file so the styles would work.

Challenges and Solutions:

One part that was a little challenging was the quiz section because the image needed to be next to the form. I decided to use Flexbox instead of floats because it was easier to line things up.

Styling the table was another challenge. I used border collapse, added background colors to the rows, and styled the table headers so it was easier to read. I also added padding to the table cells to give everything more space.

I adjusted the font sizes and spacing to match the screenshot and make the text easier to read. I also used uppercase text for some headings to match the design.

CSS Features Used:

- Selectors (IDs, elements, and hover effects)

- Box model (margin, padding, borders)

- Fonts and text styling

- Background colors

- Flexbox for layout

- Media queries for smaller screens
